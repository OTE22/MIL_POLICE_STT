# Annotating a report template

In **سجل النسخ**, expand a version and choose **حذف القالب** to permanently remove an unused, inactive template version after confirmation. Active versions must first be replaced by activating another version; versions referenced by issued reports cannot be deleted. The server enforces these checks, records the deletion in the audit log, removes the template file after database commit, and does not reuse deleted version numbers. Existing issued reports remain intact.

Open **القالب الرسمي للمحضر**, or **تصميم قالب المحضر** from the report composer. Template management requires the existing template-manager permission.

1. Choose **تصميم قالب من نموذج** and upload a blank PDF (one to thirty pages) or PNG/JPEG, up to 12 MB per file. Export Word samples to PDF first.
2. Select a field, then drag across the sample to draw its box. Drag a box to move it; use its position, width, height and font controls to refine placement. Coordinates are relative to the sample page and survive resizing the editor.
3. Use the thumbnails or page selector to navigate. Add more files, move pages earlier/later, or delete unwanted pages; **تراجع** and **إعادة** provide undo/redo (up to fifty edits). Zoom up to 400%, centred on the selected field, or expand the workspace. **تحديد وتحريك** is the default tool; choose **رسم حقل** to draw, or use the add-field button. Eight handles resize each box from any edge or corner.
   Rulers and position/size controls use millimetres measured from the top-left of each page. Type measurements to 0.1 mm and press Enter or leave the input to apply. Enable the 1/2/5/10 mm grid and automatic alignment to snap to it; with the grid hidden, alignment still snaps to field/page edges and centres. Pink guides identify the aligned edge/centre. Hold Alt while dragging to bypass snapping. Page alignment buttons position a selected box at the edges or centres. Overlapping fields are flagged without preventing intentional overlaps.
   With a field selected on the page, arrow keys move it 0.5 mm, Shift+arrows move it 5 mm, Ctrl+D duplicates it, and Delete removes it. Ctrl+Z undoes; Ctrl+Shift+Z redoes. The grid, rulers, selection outlines and guides are editor aids and are not printed. Zoom is relative to available editor width, not physical screen size; saved coordinates remain relative to the original document page.
   **تكرار الحقل على باقي الصفحات** copies the selected field to pages that do not already contain that field, using the same relative position. The limit is thirty pages per template and sixty boxes per page. Page order and each page's dimensions are preserved when saving and reopening.
4. Save a new template version and download the Word preview. Verify alignment, Arabic text and available space in Word before activating the version in the history list.
5. Use **تعديل مربعات الحقول** to reopen an annotated version; saving always creates a new version. Original uploaded Word templates remain supported through the existing upload path.

The sample image is printed as the background. Boxes cover their contents with white and insert the selected data; everything outside boxes remains visible, so start with a blank form. Short fields belong in fixed boxes. Introduction, questions/answers, closing text and signature space are generated on following pages with normal pagination. Oversized field text is rejected using a conservative capacity check; this does not replace visual review of the Word preview.

The report workflow is **select recordings → review speakers and text → save header and Q&A edits → check readiness → issue → download**. A finalized report is read-only; reopening creates a working draft for a new version while preserving issued documents. Optional formal-Arabic AI rewriting requires a running local model, but manual editing and issuing do not.

Implementation: sample PDF rasterization follows the [PDFium Python API](https://pypdfium2.readthedocs.io/en/v4/python_api.html). Rendering stays local. Templates store editable box metadata alongside the DOCX and reuse existing validation, activation, audit and immutable report-storage paths.

Page previews use compressed JPEG images and lazy thumbnail loading. Combined normalized page images are limited to 8 MB so the generated DOCX (including editable metadata) fits the existing 20 MB template upload limit. For unusually dense scans, reduce the source resolution or remove unnecessary pages. Older PNG-based layouts remain readable; newly saved copies are normalized. Unsaved edits are indicated and closing/replacing the designer or refreshing the browser prompts before discarding them.
