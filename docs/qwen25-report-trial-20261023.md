# Installed Qwen2.5 report trial — 2026-10-23

Tested only the already installed `qwen2.5:1.5b` (Q4_K_M) with local Ollama 0.12.3.
Model digest: `65ec06548149b04c096a120e4a6da9d4017ea809c91734ea5631e89f96ddc57b`.
No models or packages were downloaded; the installed model inventory was unchanged.
No application settings, report records, transcript records or production model selection changed.

The fixture is fictional: four Arabic speaker fragments spanning 12.5 seconds,
one investigator note, five identity fields, and an old filled style example.
It uses a short identity pattern adapted from the existing M53 form, not a full
document or any real previously issued report.

| Variant | Elapsed | Observed result |
| --- | ---: | --- |
| Model receives old example and current fragments; fills fields and rewrites Q&A | 56.321 s, including 13.185 s model load | Copied the old question/answer, attributed the question to the wrong speaker, and omitted the stated year, birthplace and residence. Name and missing-phone values were correct, but name had no source reference. Note was preserved. |
| Model extracts only fields; code copies Q&A and note and controls layout | 13.056 s, including 0.088 s model load | All five values correct: رامي ناصر, 1994, صيدا, بيروت, phone=null. Model omitted source IDs for all four populated fields. Q&A, notes, order and negative statements were preserved by code, not generated by the model. |

Ollama reported about 1.45 GB loaded for the CPU runner and 4096-token context,
with no GPU memory used during the first run. This is not total machine memory.
These are two executions of one small fixture, not an accuracy benchmark.

The field extraction variant is worth further testing. This result does not support
letting the 1.5B model imitate an old report freely. Template rendering, segment
ordering, notes and source linking should remain application responsibilities;
model output needs validation before use in a report.

Reproduce from the repository root (standard library only):

```powershell
python scripts/evaluate_ollama_report.py
python scripts/evaluate_ollama_report.py --extract-only
```

The script refuses to run if the exact model is absent and has no download path.
