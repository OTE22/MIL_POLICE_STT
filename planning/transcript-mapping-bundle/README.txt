HOW TO USE

1. Open Codex inside your existing application repository.
2. Paste the entire contents of START_HERE_CODEX_PROMPT.txt. It already includes the Arabic draft blueprint and synthetic JSON example; the other files are convenient separate copies.
3. Optionally add arabic_report_template_draft.html as a visual reference. It is static HTML, not an app and not a functioning export feature.
4. If you have the currently authorized blank DOCX, provide it to Codex. Otherwise the prompt explicitly asks Codex to build only a clearly labelled draft fallback.
5. Review the speaker assignments, field mapping, and generated Word output before using any result.

The design source is a scanned 2012 example, not proof of current official approval. No sample names, identifiers, case facts, signatures, stamps, or conclusions were copied. The JSON contains synthetic test speech only and is deliberately not ready for reviewed export.

Signatures are deferred. Implement only transcript mapping, human review, versioned edits/audit, and DOCX/PDF exports. Blank signature lines remain purely visual placeholders. No signing capture, certificate services, or signature-related export requirements belong in this version.

This bundle contains implementation instructions and reference templates, not a completed integration or certified government form. Exported records are reviewed documents, not signed documents.
